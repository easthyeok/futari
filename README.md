# 우리의 타임라인 💑

커플을 위한 추억 관리 웹앱입니다. 설치나 빌드가 전혀 필요 없어요.
`index.html`을 브라우저로 열기만 하면 바로 동작합니다. (React는 `vendor/` 폴더에 포함)

## 기능

| 탭 | 내용 |
|----|------|
| 🏠 홈 | D-day 카운터, 다가오는 기념일, 작년 오늘 회상, 통계, 레벨(7단계), 배지(8종) |
| 📖 추억 | 날짜 + 제목 + 메모 + 사진 기록, 날짜순 타임라인 |
| 🗺️ 지도 | 지도를 눌러 다녀온 장소에 핀 찍기 (OpenStreetMap, 무료) |
| ⭐ 버킷 | 버킷리스트 추가/체크, 완료 → 추억으로 전환 |
| 📅 약속 | 데이트 약속 일정 관리, D-day 표시, 완료 → 추억으로 전환 |
| 🎲 놀이 | 매일 바뀌는 질문 카드, 오늘 기분 공유, 소소한 투표 |
| ⚙️ 설정 | 이름/만난 날, 기념일 등록, 백업 내보내기/가져오기 |

## 파일 구조

```
index.html   화면 뼈대 + 스타일
app.js       앱 로직 (순수 JavaScript)
vendor/      react, leaflet 라이브러리 (로컬 포함)
```

## 데이터는 어디에 저장되나요?

데이터는 그 브라우저의 localStorage에만 저장됩니다.
- 같은 기기 + 같은 브라우저에서는 유지돼요.
- 다른 기기로 옮기거나 브라우저 데이터를 지우면 사라집니다.

➡️ 설정 탭의 **백업 내보내기**로 파일을 저장하고, 다른 기기에서 **백업 가져오기**로 복원하세요.

## GitHub Pages로 무료 배포하기

1. GitHub에 새 저장소를 만듭니다. (예: `couple-timeline`)
2. 이 폴더의 모든 파일을 저장소에 올립니다. (`index.html`, `app.js`, `vendor/`, `README.md`)
3. 저장소 → **Settings → Pages** 로 이동
4. **Source**를 `Deploy from a branch`, Branch를 `main` / `/ (root)`로 선택하고 저장
5. 잠시 후 `https://<사용자명>.github.io/couple-timeline/` 주소로 접속하면 끝!

이 주소를 공유하면 누구나 각자 기기에서 열 수 있어요.
단, 지금 버전은 데이터가 각 기기에 따로 저장됩니다. 두 사람이 같은 데이터를 실시간 공유하려면
Supabase 같은 DB 연동이 필요합니다.
