# futari 💑

선택과 반응으로 둘만의 집과 추억을 쌓는 웹앱입니다. 빌드 없이 정적 웹 서버에서 실행합니다.

## 기능

| 탭 | 내용 |
|----|------|
| 🏡 우리 집 | 오늘 기분, 마음 보내기, 둘이 고르기, 함께한 시간, 집 성장 |
| 💛 함께하기 | 약속·달력, 버킷리스트, 오목·다빈치코드·바운스오프 |
| 📖 추억 | 자동 생성된 추억과 기존 기록, 검색·수정 |
| ⚙️ 상단 설정 | 사용자 변경, 이름·기념일, 초대 링크, 백업 |

각 기기에서 처음 한 번 자신의 이름을 선택합니다. 상대의 기분과 선택을 대신 입력하지 않습니다.
기분과 반응은 각각 하루 1개씩, 둘이 고르기와 함께한 시간은 두 사람 참여 시 각각 마음 3개가 쌓입니다.
10개마다 화분·조명·러그·고양이가 나타납니다. 접속하지 않아도 쌓인 마음은 줄지 않습니다.
둘이 선택을 마치거나 함께한 시간을 확인하면 추억이 자동으로 생성됩니다.
이 사용자 선택은 편의 기능이며 인증이나 접근 권한을 대신하지 않습니다.

새로운 추억은 사진 없이 텍스트로 저장합니다. 이전에 저장한 사진은 유지되며 추억에서 눌러 크게 볼 수 있습니다.

## 실행

```sh
python3 -m http.server 8000
```

서버가 출력하는 주소로 접속하세요. React와 Supabase 클라이언트는 `vendor/`에 포함되어 있습니다.
공유 저장에는 인터넷 연결 및 `config.js`의 Supabase 연결 설정이 필요합니다. 지도 SDK와 지도 API 키는 사용하지 않습니다.

## PWA 설치와 GitHub Pages

배포 주소: https://easthyeok.github.io/futari/

`manifest.webmanifest`에 앱 이름, 192/512px PNG 아이콘, `standalone` 표시 모드와 시작 경로를 정의했습니다. 모든 경로는 상대 경로여서 `/futari/`에 배포할 수 있습니다. 실제 배포 서버의 응답과 브라우저 설치 판정은 별도로 확인해야 합니다.

- HTTPS 주소를 크롬에서 직접 여세요. 카톡 등의 앱 내부 브라우저 대신 크롬을 사용하세요.
- 설치 가능한 상태가 되면 화면 상단의 ‘앱 설치’를 누르거나 크롬 메뉴에서 ‘앱 설치 / 홈 화면에 추가’를 선택하세요. 설치 안내가 바로 나타나는 시점은 브라우저 상태와 사용 이력에 따라 달라집니다.
- iPhone은 Safari 공유 메뉴의 ‘홈 화면에 추가’를 사용하세요.
- 개발용 `http://localhost:8000`은 서비스 워커를 사용할 수 있지만 휴대폰에서 PC의 `http://192.168…` 주소로 접속하면 보안 연결 요건을 충족하지 못합니다.

Chrome DevTools → Application에서 Manifest의 아이콘·시작 주소·오류와 Service Workers의 활성 상태를 확인하세요. Network의 Offline을 켜고 새로고침하여 화면이 열리는지 확인하세요. 매니페스트와 아이콘 URL이 HTML 오류 페이지 대신 실제 JSON/PNG로 응답해야 합니다.

서비스 워커는 앱 파일만 캐시하며 Supabase 요청과 방 코드가 담긴 URL을 캐시하지 않습니다. 앱의 방 데이터는 기존처럼 방별 localStorage에 보관합니다. 앱 화면이 바뀌면 `sw.js`의 `CACHE_NAME` 버전을 올리세요. 새 버전은 기존 탭과 설치 앱 창을 모두 닫고 다시 열면 적용됩니다. 편집 도중 강제로 새로고침하지 않습니다.

## 둘이 보드게임

함께하기 → 보드게임에서 선택하세요. 사목·주사위 레이스·카드 덱은 제거했습니다.

### 오목 · 각자 기기에서 이어하기

15×15 자유 오목입니다. 금수 없이 가로·세로·대각선으로 5개 이상 이으면 승리합니다. 작은 화면에서 실수로 두지 않도록 칸을 선택한 뒤 확인 버튼으로 착수합니다.

### 다빈치코드 · 각자 기기에서 이어하기

조커 없는 0~11 검정·흰색 타일 24개를 사용하며 각자 4개로 시작합니다. 작은 숫자가 왼쪽이고, 같은 숫자는 검정이 먼저입니다.

- 자기 차례에 검정/흰색 타일을 뽑고 상대의 비공개 타일을 선택해 숫자를 추리합니다.
- 정답이면 상대 타일을 공개합니다. 계속 추리하거나 멈추고 뽑은 타일을 비공개로 내 코드에 넣을 수 있습니다.
- 오답이면 뽑은 타일을 공개해 내 코드에 넣고 차례를 넘깁니다. 상대 코드를 모두 공개하면 승리합니다.
- 타일을 모두 뽑은 뒤에는 오답 시 자신의 맨 왼쪽 비공개 타일을 공개하는 앱 규칙을 사용합니다.

오목과 다빈치코드는 시간제한이 없습니다. 방의 `boardGames`에 상태를 저장하므로 화면 이동·새로고침·며칠 뒤 재접속 후에도 같은 판을 이어갑니다. 기기에서 선택한 사용자만 자기 차례를 진행합니다. 새 판은 상대의 수락 후 시작하며 기다리는 동안 기존 판은 유지됩니다. 게임 버튼의 점은 내 차례를 나타냅니다.

다빈치코드의 비공개 숫자는 상대 화면의 텍스트·접근성 이름에 표시하지 않습니다. 현재 방 전체 JSON을 두 기기에 전달하는 구조라 개발자 도구나 사용자 변경까지 막는 서버 수준의 비밀 보장은 없습니다. 지인 간 플레이를 위한 화면 숨김이며, 완전한 비공개를 위해서는 사용자 인증과 서버 게임 처리 API가 필요합니다.

### 바운스오프 · 휴대폰 한 대에서 번갈아 하기

공을 뒤로 당겼다가 놓아 방향과 힘을 조절합니다. 공이 튕겨 날아가 빈 구멍에 들어가면 판에 남습니다. 목표 패턴을 같은 색 공으로 완성하면 카드를 얻으며 위치 이동과 회전이 가능합니다. 카드 3장을 먼저 모으면 경기에서 승리합니다.

각자 카드당 공 8개를 사용하고, 둘 다 소진하면 같은 카드의 판을 비우고 다시 도전합니다. 이미 공이 있는 칸이나 구멍 밖에 떨어지면 실패합니다. 키보드는 방향키로 조준하고 Enter 또는 Space로 던집니다.

바운스오프는 이 화면에서만 진행과 점수를 유지하며 화면을 나가면 초기화됩니다. 실시간 조작용 로컬 게임이며 두 기기 간 진행은 공유하지 않습니다.

기존 장소 기록은 백업 호환성을 위해 보존되지만 지도 화면은 제거했습니다.

## 데이터와 동기화

같은 방 코드를 입력하면 Supabase `rooms` 테이블의 데이터를 함께 사용합니다. 기기에는 방 코드가 기억됩니다.
일반 변경은 마지막 입력 후 약 1.2초 뒤 저장하고, 공유 보드게임의 수는 대기 시간 없이 저장을 시작합니다. 상대방의 변경은 약 10초마다 확인하며 앱으로 돌아왔을 때도 바로 조회합니다. 저장이 완료되기 전에 종료한 변경은 이 기기에 보관됩니다.
저장 실패 메시지를 누르면 다시 시도합니다. 저장하지 못한 변경이 있으면 원격 조회로 덮어쓰지 않습니다.

방 전체 데이터를 저장하며 `updated_at`이 읽었던 버전과 같을 때만 갱신합니다. 상대가 먼저 저장하면 덮어쓰기를 중단하고 오류를 표시합니다. 자동 병합은 지원하지 않습니다. 충돌 시 설정에서 현재 내용을 백업한 후 ‘상대 변경 불러오기’를 눌러 미저장 변경을 버리고 서버 기록을 확인하세요. 실제 Supabase에서 SELECT·UPDATE 정책과 updated_at 컬럼을 확인해야 합니다.
최근 방 데이터와 미저장 변경은 방별로 기기에 보관합니다. 다시 접속하면 최근 화면을 먼저 표시하고 동기화합니다. 서비스 워커가 앱 화면과 정적 파일을 보관해 처음 온라인으로 방문한 뒤에는 오프라인에서도 최근 방 화면을 열 수 있습니다. 새 방 입장과 상대와의 동기화는 인터넷이 필요합니다. 푸시 알림은 아직 지원하지 않습니다.
설정의 백업 내보내기로 데이터를 별도 보관할 수 있습니다. 백업 가져오기는 현재 방의 데이터를 교체합니다.

## 파일

- `index.html`: 화면과 스타일
- `app.js`: React 앱과 공유 저장 로직
- `home.js`: 우리 집 화면, 공동 활동, 자동 추억과 성장 규칙
- `games.js`: 바운스오프 규칙·터치 조작·게임 화면
- `board-games.js`: 오목·다빈치코드 규칙, 공유 게임 화면과 새 판 합의
- `manifest.webmanifest`: 설치 이름, 아이콘, 시작 경로
- `pwa.js`: 설치 버튼과 서비스 워커 등록
- `sw.js`: 앱 파일의 오프라인 캐시
- `icons/`: 설치 아이콘과 iOS 홈 화면 아이콘
- `config.js`: Supabase 연결 설정
- `vendor/`: 브라우저 라이브러리
- `tests/features.cjs`: 외부 서비스에 연결하지 않는 기능 검증

## 검증

```sh
node --check app.js
node --check games.js
node --check board-games.js
node --check home.js
node tests/features.cjs
node tests/games.cjs
node tests/sync.cjs
node --check sw.js
node --check pwa.js
node tests/pwa.cjs
```

검색·수정·기존 사진 보존·달력·룰렛·공동 활동 외에 바운스오프 터치·착지·회전 패턴·승리, 오목 판정, 다빈치코드 추리·턴 전환·숫자 화면 숨김, 재접속용 상태 보존과 새 판 합의를 확인합니다.
PWA 검증은 매니페스트·PNG 크기, 루트/하위 경로의 시작 주소, 서비스 워커의 오프라인 응답·캐시 분리, 설치 버튼 이벤트를 확인합니다. 이 검증은 브라우저 렌더링, 실제 크롬 설치 판정이나 Supabase 연결을 대신하지 않습니다.
