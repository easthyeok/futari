# futari 💑

둘만의 추억과 데이트 계획을 함께 기록하는 웹앱입니다. 빌드 없이 정적 웹 서버에서 실행합니다.

## 기능

| 탭 | 내용 |
|----|------|
| 🏠 홈 | D-day, 다가오는 기념일, 작년 오늘의 추억, 통계, 레벨과 배지 |
| 📖 추억 | 텍스트 추억 추가·수정·삭제, 제목/메모 검색, 월별 필터 |
| 🗺️ 지도 | 카카오맵에서 다녀온 장소 기록 |
| ⭐ 버킷 | 카테고리별 버킷리스트, 완료한 일을 추억으로 전환 |
| 📅 달력 | 약속·추억·매년 반복되는 기념일을 월별로 보기, 선택한 날짜에 약속 추가 |
| 🎲 놀이 | 미완료 버킷리스트로 데이트 룰렛, 질문 카드, 기분, 투표 |
| ⚙️ 설정 | 이름과 만난 날, 기념일, 방 코드, JSON 백업/복원 |

새로운 추억은 사진 없이 텍스트로 저장합니다. 이전에 저장한 사진은 유지되며 추억에서 눌러 크게 볼 수 있습니다.

## 실행

```sh
python3 serve.py
```

서버가 출력하는 주소로 접속하세요. React와 Supabase 클라이언트는 `vendor/`에 포함되어 있습니다.
카카오맵과 공유 저장에는 인터넷 연결 및 `config.js`의 연결 설정이 필요합니다.

## 데이터와 동기화

같은 방 코드를 입력하면 Supabase `rooms` 테이블의 데이터를 함께 사용합니다. 기기에는 방 코드가 기억됩니다.
변경은 마지막 입력 후 약 1.2초 뒤 저장하고, 상대방의 변경은 약 10초마다 확인합니다.
저장 실패 메시지를 누르면 다시 시도합니다. 저장하지 못한 변경이 있으면 원격 조회로 덮어쓰지 않습니다.

현재 방 전체 데이터를 저장하므로 두 기기가 동시에 편집할 때 충돌을 완전히 방지하지는 못합니다.
설정의 백업 내보내기로 데이터를 별도 보관할 수 있습니다. 백업 가져오기는 현재 방의 데이터를 교체합니다.

## 파일

- `index.html`: 화면과 스타일
- `app.js`: React 앱과 공유 저장 로직
- `config.js`: Supabase와 카카오맵 연결 설정
- `vendor/`: 브라우저 라이브러리
- `tests/features.cjs`: 외부 서비스에 연결하지 않는 기능 검증

## 검증

```sh
node --check app.js
node tests/features.cjs
```

검색, 수정, 기존 사진 보존, 사진 없는 추억 생성, 달력 선택과 윤년/연도 이동, 룰렛을 확인합니다.
이 검증은 브라우저 렌더링이나 실제 Supabase 연결을 대신하지 않습니다.
